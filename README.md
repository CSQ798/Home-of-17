## 一、怎么打开

- **最简单**：双击 `index.html`，用 Chrome / Edge / Firefox 打开。
- 若浏览器限制本地文件读取（脚本或本地存储不工作时），在本目录起一个静态服务器：

  ```powershell
  python -m http.server 8000
  # 或
  npx --yes serve -l 8000
  ```

  然后访问 <http://localhost:8000/>。

### 卷首怎么加文字

打开 `assets/js/data-content.js`，找到 `window.PREFACE`，在 `blocks` 数组里按顺序添加即可：

```js
blocks: [
  B.p('一段普通的段落。'),
  B.p('段落里可以用 **粗体** 和 [链接](https://…)。'),
  B.h('小标题'),
  B.ul(['第一条', '第二条']),
  B.ol(['第一步', '第二步']),
  B.idea('核心观点', '这一块会整块反白，全站最重要的句子放这里。'),
  B.note('提示', '普通提示块：细黑框 + 粗黑左边线。'),
  B.q('引用的话', '出处'),
  B.table(['列一', '列二'], [['a', 'b']]),
  B.steps([{ title: '第一步', x: '说明' }]),
  B.kv([['关键词', '解释']]),
  B.check('可勾选清单', ['勾选状态会自动保存'])
]
```

> 新增一篇文章后，**左侧导航、面包屑、右侧目录、上一页 / 下一页、全站搜索会自动全部更新**——导航与翻页顺序都由 `R.flatPages()` 从数据推导。

### 更新后页面还是旧的？把缓存版本号 +1

`index.html` 引用 CSS / JS 时带了版本号，例如：

```html
<link rel="stylesheet" href="assets/css/style.css?v=2">
<script src="assets/js/app.js?v=2"></script>
```

这是防止浏览器和 CDN 缓存旧文件用的。**改完样式或脚本、重新部署之后，如果发现页面上还是旧的**，就把 `index.html` 里所有 `?v=2` 一起改成 `?v=3`（下次改 `?v=4`，以此类推），所有访客就会立刻拿到新文件。

> 站点的 `_headers` 里**故意没有**给 `/assets/*` 设长时间缓存，就是为了让更新能马上生效；版本号只是第二道保险。

### 字体说明

默认使用本机字体：拉丁文用 Georgia（衬线）、中文用宋体、标签用 Consolas 等宽字体，因此在离线与国内网络下都能正常显示。
如果你能访问 Google Fonts，可以在 `index.html` 里取消那段注释，启用 Playfair Display / Source Serif 4 / JetBrains Mono。

## 四、读者想说（全站最后一页）

**整站只有一处留言区**：地址是 `#/letters`，标题「读者想说」，位置在导航最末（关于本站之后），页脚也有入口。
首页、卷首、22 篇文章、工具页、资源库、关于页**都不再插入留言区**，阅读过程不会被反复打断；读者读到最后自然就到了这里。

这一页包含：

- **三个引导问题** —— 给不知道怎么下笔的人一个开头
- **署名 + 正文输入框** —— 署名可以随便写，不用真名
- **四个按钮**：`保存，并显示在下面` / `寄给作者` / `复制内容` / `清空`
- **「我写过的」** —— 保存后立刻出现在这一栏里，只存在读者自己的浏览器
- **「来信」墙** —— 作者挑选后公开的留言

> 想把它挪到别处（比如某一篇文章末尾），改 `assets/js/render.js` 里的 `lettersPageHtml` 调用位置即可；
> 或者把 `pageWrap` 里的 `lettersBodyHtml()` 加回其他页面——那是一行代码的事。

### 为什么是这样设计的

这是一个**纯静态网站，没有服务器**。所以「读者写完，所有人都能立刻看到」这件事，在没有后端的情况下做不到——必须外接一个评论服务。

默认的**来信模式**把这件事变得可行且可控：

| 读者做了什么 | 发生了什么 |
| --- | --- |
| 点「保存」 | 留言立刻出现在页面上（只在他自己的浏览器里，别人看不到） |
| 点「寄给作者」 | 打开邮件应用，把留言发到 `1876148307@qq.com` |
| 点「复制内容」 | 复制到剪贴板，手机上没配邮箱时用这个 |

你收到邮件后，把想公开的挑选出来，加进「来信」墙即可。好处是：**面向高中生的页面，所有公开内容都经过你的手**，不会出现脏话、广告或不当内容。

### 怎么往「来信」墙加一条

打开 `assets/js/data-library.js`，找到 `window.LETTERS.letters`：

```js
letters: [
  {
    name: '高二 · 小林',        // 署名
    date: '2026-03',            // 日期
    text: '留言正文，支持 **粗体** 和 [链接](https://…)',
    reply: '作者回复（可以省略这一行）'
  },
],
```

保存后刷新页面就能看到。数组为空时页面会显示「还没有公开的来信。你的可以是第一封。」，这句话在 `wallEmpty` 里改。
引导问题、按钮文案、输入框提示语也都在同一个 `window.LETTERS` 对象里，可以随意改。

### 让读者互相看见留言（可选升级）

如果你确实想要一个「所有人都能实时看到彼此留言」的公开留言板，在 `assets/js/data-library.js` 里配置 `window.COMMENTS` 即可，页面会自动在留言区下方加载评论组件：

```js
window.COMMENTS = {
  provider: 'twikoo',                            // 改成 twikoo / giscus / waline
  twikoo: { envId: '你的环境ID或部署地址', cdn: '…' },
  giscus: { repo: '用户名/仓库', repoId: '…', category: 'Announcements', categoryId: '…' },
  waline: { serverURL: 'https://你的-waline-地址' }
};
```

| 方案 | 读者要登录吗 | 国内可访问 | 需要部署后端 |
| --- | --- | --- | --- |
| **Twikoo**（推荐） | 不用，填昵称即可 | ✅ 可部署到腾讯云开发 | 需要（约 10 分钟，免费额度够用） |
| Waline | 不用，填昵称即可 | 看部署在哪（Vercel 国内不稳） | 需要（Vercel + 数据库） |
| giscus | **必须用 GitHub 账号** | ❌ 高中生大多没有，且 GitHub 访问慢 | 不需要 |

- Twikoo 文档：<https://twikoo.js.org/>
- Waline 文档：<https://waline.js.org/>
- giscus：<https://giscus.app/zh-CN>

> 把 `twikoo.cdn` 默认的 jsdelivr 换成国内更快的地址（如 `https://npm.elemecdn.com/twikoo@1.6.44/dist/twikoo.min.js`）加载会更快。
> 提醒：一旦开放公开留言，审核责任就在你自己身上了。面向未成年人的站点，建议保留「来信 + 挑选」模式，或至少开启 Twikoo 的评论审核。

## 五、设计系统要点（Minimalist Monochrome）

- **只有黑白**：文字纯黑 `#000`、背景纯白 `#fff`，灰色仅用于次要文字与细线；没有第二品牌色。
- **零圆角、零投影**：所有元素直角，深度只靠反白、线宽与留白表现。
- **衬线字体当主角**：标题用衬线体并可放大（首页主标题 `clamp(3.2rem, 13vw, 9rem)`）。
- **线构成结构**：1px 细线分隔、2px 边框、4px 小节顶线、8px 章节与页脚重线。
- **反白做强调**：核心观点整块反白、卡片与导航项悬停反白、深色主题即整体反转。
- **瞬时交互**：交互过渡一律 ≤100ms；只有呼吸练习的圆环按 4 秒节奏缩放。
- **纸张质感**：全站叠了一层极淡的横纹与噪点。
