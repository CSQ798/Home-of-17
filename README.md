# Home of 17.

写给高中生的四件事：**过程永远比结果更重要 · 摒弃功利化的思想、学会慢下来 · 要有长远的眼光 · 弄明白你为什么学习。**

一个纯静态的个人站点（零依赖、零构建，双击即可打开），采用 MkDocs Material 式的文档结构 + **Minimalist Monochrome**（黑白编辑风）视觉系统：左侧常驻导航树、中间正文、右侧本页目录，顶部搜索，底部翻页。

## 一、怎么打开

- **最简单**：双击 `index.html`，用 Chrome / Edge / Firefox 打开。
- 若浏览器限制本地文件读取（脚本或本地存储不工作时），在本目录起一个静态服务器：

  ```powershell
  python -m http.server 8000
  # 或
  npx --yes serve -l 8000
  ```

  然后访问 <http://localhost:8000/>。

### 卷首怎么加文字

打开 `assets/js/data-content.js`，找到 `window.PREFACE`，在 `blocks` 数组里按顺序添加即可：

```js
blocks: [
  B.p('一段普通的段落。'),
  B.p('段落里可以用 **粗体** 和 [链接](https://…)。'),
  B.h('小标题'),
  B.ul(['第一条', '第二条']),
  B.ol(['第一步', '第二步']),
  B.idea('核心观点', '这一块会整块反白，全站最重要的句子放这里。'),
  B.note('提示', '普通提示块：细黑框 + 粗黑左边线。'),
  B.q('引用的话', '出处'),
  B.table(['列一', '列二'], [['a', 'b']]),
  B.steps([{ title: '第一步', x: '说明' }]),
  B.kv([['关键词', '解释']]),
  B.check('可勾选清单', ['勾选状态会自动保存'])
]
```

> 新增一篇文章后，**左侧导航、面包屑、右侧目录、上一页 / 下一页、全站搜索会自动全部更新**——导航与翻页顺序都由 `R.flatPages()` 从数据推导。

### 字体说明

默认使用本机字体：拉丁文用 Georgia（衬线）、中文用宋体、标签用 Consolas 等宽字体，因此在离线与国内网络下都能正常显示。
如果你能访问 Google Fonts，可以在 `index.html` 里取消那段注释，启用 Playfair Display / Source Serif 4 / JetBrains Mono。

## 四、设计系统要点（Minimalist Monochrome）

- **只有黑白**：文字纯黑 `#000`、背景纯白 `#fff`，灰色仅用于次要文字与细线；没有第二品牌色。
- **零圆角、零投影**：所有元素直角，深度只靠反白、线宽与留白表现。
- **衬线字体当主角**：标题用衬线体并可放大（首页主标题 `clamp(3.2rem, 13vw, 9rem)`）。
- **线构成结构**：1px 细线分隔、2px 边框、4px 小节顶线、8px 章节与页脚重线。
- **反白做强调**：核心观点整块反白、卡片与导航项悬停反白、深色主题即整体反转。
- **瞬时交互**：交互过渡一律 ≤100ms；只有呼吸练习的圆环按 4 秒节奏缩放。
- **纸张质感**：全站叠了一层极淡的横纹与噪点。

## 五、数据与隐私

- 纯静态网页，**没有服务器、没有账号、没有上报**。
- 你在工具里填写的内容只保存在自己浏览器的 localStorage 中；换设备不会同步，建议用工具页的「导出全部数据（JSON）」备份。
- 公共电脑上使用后，可在「方法与工具」页点「清空全部记录」。
